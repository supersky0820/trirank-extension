# Privacy

The privacy policy for this extension is published at
<https://trirankai.com/privacy> — see the section **The TriRank Browser
Extension**, which describes exactly what the panel reads from a page, what
leaves your device, and what is stored and for how long.

Each tagged release in this repository (`v1.8.0`, …) is byte-for-byte the
archive packaged under that version, and for every version the Chrome Web Store
accepted it is the archive that was submitted. `main` may run ahead of the
version the store is currently serving, and a tag can exist for a build that was
packaged but not yet submitted — see [CHANGELOG.md](CHANGELOG.md) for which
version is live.

Every request the extension makes is listed in [README.md](README.md) under
**What it sends**.
